# 按需安装 MCP 工具

Orbit 的服务端包保留 Web 界面、身份校验、对话调度、数据库、设置与基础能力。浏览器、文件、图表、地图、代码沙箱、知识库、多媒体、本地终端和电脑操作分别安装、分别启动。

## 安装与配置

在「设置 → 环境 → 工具能力 → 工具组件」中选择一个工具安装。安装完成后启用。接口只接受单个工具 ID，没有「安装全部」操作。没有安装或已禁用的工具不会注册到对话执行器，也不会出现在对话工具入口中。

「配置」支持该工具独立的环境变量和 SDK 分组 JSON，例如：

```json
{
  "tools": {
    "media": { "timeoutMs": 180000 }
  }
}
```

环境变量值加密保存在数据库，读取设置时只返回名称；留空保留原值，移除行会删除对应变量。保存会停止旧 MCP 进程，下次调用创建新进程。正在执行的工具会拒绝配置和卸载操作。

全局工具开关、用户权限和部署权限继续生效。安装终端或电脑工具不会授予宿主执行权限；代码沙箱仍需部署允许的隔离执行后端。

## MCP 加载方式

每个组件只包含所选 SDK provider 的模块图和必要依赖。安装过程会执行 npm 安装、准备该工具所需运行环境，并通过真实 MCP 初始化及 `tools/list` 校验入口。校验成功才发布为可用版本。

进程按用户、对话、执行范围和配置隔离，首次调用才启动；闲置后回收。终端按对话保留实例，使模型和终端面板操作同一个工作区；终端面板通过增量读取转发输出，关闭对话时回收对应 MCP 进程。进程环境独立，不会修改 Orbit 的全局 `process.env`。附件先进入当前对话的受限工作目录，产物链接再转换为 Orbit 的鉴权下载地址。知识库仍指向部署共享目录，对话检索使用只读权限。

浏览器 MCP 连接主程序拥有的具体 Chromium target，沿用会话分组；新标签的选择会同步给右侧预览，拒绝操作其他会话的 target。关闭借用的 MCP 连接不会关闭宿主浏览器。媒体模型配置沿用 Orbit 已保存的模型配置，合成视频继续保存可编辑项目。

## 运行环境与 Docker

基础镜像不预装 Electron、Chromium、LibreOffice、FFmpeg、Remotion 等可选工具依赖和大型运行环境。它携带 SDK 的安装模板代码，安装时再生成单个组件包。Web 自身需要的浏览器端预览代码仍在前端产物中。

基础镜像中的系统 Python 和 util-linux 用于 Landlock 安全隔离监督进程；不包含 pip、Office 或工具 Python 虚拟环境。代码工具需要的 Python 环境另行下载。

组件打包支持依赖映射。终端的 `node-pty` 使用固定版本的 [当前平台预编译分发](https://github.com/lydell/node-pty)，保持原调用接口，避免在运行容器中安装 C++ 编译器。基础镜像不包含该终端模块或编译工具链。

默认组件目录为 `APP_DATA_DIR/tool-components`，可用 `CAPABILITY_TOOLS_HOME` 指定。Docker Compose 使用 `orbit-tool-components` 持久卷，Web 容器可写，代码沙箱容器只读挂载。升级时保留该卷。Linux 的浏览器/Office 系统库下载并提取到组件运行目录，不依赖容器可写层中的 apt 安装结果。

卸载会删除所选工具的程序和依赖；对话、产物和其他工具可能使用的共享运行环境保留。工具下载和数据卷不计入纯净基础镜像体积。

## 第三方 MCP

现有 MCP 设置增加了「MCP 本地进程」驱动，可配置命令、参数数组、工作目录和环境变量 JSON。每个服务使用独立环境；Windows 的 `.cmd` / `npx` 命令通过 SDK 的进程传输启动。

远程 HTTP MCP 继续使用现有驱动。远程服务只有声明了配置接口时，Orbit 才能修改其服务配置；MCP 协议本身不支持修改远端进程的环境变量。

## 验证范围

验证使用独立数据库、组件目录和 Docker 数据卷，不复用业务对话数据。真实检查覆盖单工具安装、失败重试、启停、卸载重装、权限、配置密文和掩码、MCP 调用、浏览器预览 target 同步、知识库只读、图表/地图、Office/PDF、桌面观察及视频合成。验收过程没有新增仓库测试源码；[本地验收记录](./managed-mcp-tools-validation.md) 记录实际运行范围和镜像测量口径。
